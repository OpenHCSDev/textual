# Tree cursor projection

Tree owns the lazy `_tree_lines` projection and assigns node lines in `_build`. Cursor validation builds that projection after its argument has already been evaluated. An unbuilt node therefore contributes -1 even when the build makes it visible, and validation selects line zero.

Acquire the original projection before reading node or current cursor lines. Close move/select, scroll-to-node, line-relative navigation and DirectoryTree restoration through the existing Tree methods. Preserve original None/reset clamping, collapsed/foreign-node behavior, selection events, animation and public node line storage; no expansion, copied selection or callback retry.
