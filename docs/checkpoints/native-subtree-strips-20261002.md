## Source contract

`Compositor.render_subtree_strips(root) -> tuple[Size, list[Strip]]` returns the original complete outer size (border/gutter included) and every root-local row. Its mounted native widget tree supplies geometry through the same compositor's `_arrange_root(root, size, visible_only=False)`. The existing geometry cache may accelerate arrangement; its presence is not paint custody. The transient body-local map is consumed by the ordinary native renderer without replacing the published screen maps or creating widgets, another compositor, cache or store. An unmounted root raises existing `errors.NoWidget`.

`Compositor.can_render_subtree(root)` reads original mounted custody without resolving geometry. Rendering reuses that admission and then reads the same compositor's current `find_widget(root).region.size` once. Current arranged extent and Screen-committed widget size are different facts: viewport/scroll layout can leave offscreen `_size` stale, even after the full map has current geometry. Capture uses current arranged bounds, not an offscreen committed-size shortcut. Screen and body rendering share `_paint_regions`, `_cuts_for_regions`, `_get_renders` and `_render_chops`; no duplicate layout or renderer is introduced. Body content measurements and outer captured rows remain distinct, so Toad consumes the rows without adding gutters again.
